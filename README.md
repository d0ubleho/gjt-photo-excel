# 물품 회수 기록

관재 업무에서 불용·반납 물품을 회수하면 신청서와 비품 사진, 자산번호 스티커 사진을 남깁니다. 이 도구는 사진을 신청서별로 묶어 제출용 엑셀을 만드는 일을 줄여줍니다. 독립 프로젝트이며, 현재 버전은 macOS에서 실행합니다.

## 설치와 실행

1. 저장소에서 **Code → Download ZIP**으로 내려받아 압축을 풉니다. Mac에 Python 3.10 이상과 Apple Command Line Tools가 필요합니다. 개발 도구가 없으면 터미널에서 `xcode-select --install`을 실행합니다.
2. 압축을 푼 폴더에서 `시작.command`를 실행합니다. 터미널에서는 그 폴더로 이동한 뒤 `zsh ./시작.command`를 실행해도 됩니다. 첫 실행은 인터넷으로 Python 패키지를 설치하고 Apple Vision OCR 프로그램을 컴파일합니다.
3. Mac에서 쓰려면 터미널의 **이 Mac** 주소를 엽니다. iPhone에서 쓰려면 같은 Wi-Fi에 연결한 뒤 **아이폰 Safari** 주소를 마지막 `/`까지 그대로 엽니다. 작업을 마치면 터미널에서 `Control+C`로 종료합니다.

포트가 이미 사용 중이면 `zsh ./시작.command --port 8766`으로 실행할 수 있습니다. Mac에서만 사용할 때는 `--bind 127.0.0.1`을 추가합니다.

## 사진에서 엑셀까지

1. 신청서, 비품 전체 사진, 자산번호 스티커 사진을 종류별로 올립니다. 각 칸에서 여러 장을 선택할 수 있습니다.
2. 읽어낸 신청번호·품명·자산번호를 원본과 대조합니다. 스티커는 자산번호가 일치하는 품목에 연결됩니다. 비품 사진과 품목이 하나씩이면 자동으로 연결되며, 여러 장이면 화면에서 사진을 고릅니다.
3. 현재 신청서만 엑셀로 받거나 신청서별 엑셀을 ZIP으로 받습니다. 한 번에 신청서 20장, 파일당 품목 50개까지 처리합니다.

## 코드 수정

| 파일 | 하는 일 |
|---|---|
| `index.html`, `app.js` | 브라우저 화면, 사진 업로드, 인식 결과 수정 및 다운로드 |
| `server.py` | HTTP 요청 처리, 임시 사진 보관, OCR과 엑셀 생성 호출 |
| `vision.swift` | Apple Vision으로 사진 속 글자 위치와 QR 읽기 |
| `recognition.py` | 글자 위치를 보고 신청서 행을 구분하고 자산번호 대조 |
| `workbook.py`, `template.xlsx` | 빈 양식에 품목 행과 사진 삽입 |
| `사진크기.json` | 엑셀 사진 열 너비와 품목 행 높이 |

처음 수정해본다면 `사진크기.json`에서 `itemRowPt`를 160에서 180으로, `photoColumnPx`를 280에서 320으로 바꾸고 같은 신청서를 다시 다운로드해 보세요. `recognition.py`의 입력은 OCR이 읽은 글자와 좌표이며, 출력은 화면에 표시할 신청 정보와 품목입니다. 인식 규칙을 수정할 때는 가짜 신청서를 여러 각도에서 찍어 기존 결과와 비교하면 됩니다.

## 사용 범위

현재는 한 사람이 Mac과 같은 네트워크에서 사용하는 도구입니다. 브라우저에 표시된 주소를 가진 기기가 접속할 수 있습니다. 사진은 Mac의 임시 폴더에서 처리하고 정상 종료 시 정리합니다. 실제 신청서, 스티커 사진, 생성된 엑셀은 저장소에 올리지 마세요.

Linux VM이나 여러 직원이 함께 사용하는 서버로 옮기려면 OCR 엔진 교체, 직원 인증, 작업별 사진 분리와 정리 기능이 필요합니다.
